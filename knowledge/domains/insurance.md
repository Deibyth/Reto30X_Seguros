# Insurance Domain — Colsubsidio

## Portfolio Overview

Colsubsidio offers insurance products across four main categories: personal/family protection, asset/patrimony protection, specialized 24/7 assistance, and credit-linked insurance. All products can be financed through the Crédito de Seguros Colsubsidio for affiliates.

Also includes optional Asesorías Jurídicas (legal advisory) as a standalone service.

---

## 🛡️ Personal & Family Protection

### 1. Seguro de Vida y Ahorro
**Dual benefit**: financial protection + savings accumulation.

| Aspect | Detail |
|--------|--------|
| **Price** | From $20,000 COP/month |
| **Requirements** | Affiliate categories A, B, or C; age 18–64 at entry; health declaration required |
| **Coverages** | Death by any cause, accidental death, total/permanent disability, dismemberment |
| **Exclusions** | First 2 years: suicide, HIV/AIDS pre-existing |
| **Extras** | Savings component accumulates capital over time; up to 15% cashback at partner merchants |
| **Financing** | Via Crédito de Seguros (up to 11 months) |

### 2. Accidentes Personales
**Immediate response** for unexpected events.

| Aspect | Detail |
|--------|--------|
| **Price** | Adjusted by number of family members enrolled; base from $25,000 COP/month |
| **Requirements** | Age 18–60 or 18–65 depending on policy annex |
| **Coverages** | Compensation for disabling injuries or death, medical expense reimbursement for emergencies, includes a "bono canasta" (basket bonus) for household expenses |
| **Extras** | Direct specialist appointments within Colsubsidio health network, bypassing EPS processes |

### 3. Póliza de Salud
**Direct access** to specialists and preferential care.

| Aspect | Detail |
|--------|--------|
| **Price** | From $80,000 COP/month |
| **Requirements** | Affiliate, age within policy limits |
| **Coverages** | Access to exclusive network of clinics and medical centers; avoids long waits in traditional subsidized system |
| **Insurers** | Sura, Allianz, Chubb |

### 4. Renta por Hospitalización
**Daily economic subsidy** for hospitalized nights.

| Aspect | Detail |
|--------|--------|
| **Price** | Included in accidentes/salud packages or standalone |
| **Coverages** | Direct daily payment per night hospitalized; compensates for non-working days |

### 5. Salud Especializada (Cáncer)
**Immediate economic support** upon cancer diagnosis.

| Aspect | Detail |
|--------|--------|
| **Price** | From $20,000 COP/month (often bundled) |
| **Coverages** | One-time economic support upon positive cancer diagnosis; freely disposable for complementary treatments |

### 6. Seguro Exequial
**Full funeral coverage** for affiliate and registered family.

| Aspect | Detail |
|--------|--------|
| **Price** | From $12,000 COP/month |
| **Coverages** | All legal procedures, wake services, funeral transport for affiliate and registered family group |
| **Extras** | Extends coverage to pets (mascotas) |

## Recommendation Rules (Motor de Reglas)

### R1–R7: Direct Rules
```
R1: vida           ← familia_con_hijos AND preocupacion == "proteger"
R2: accidentes     ← edad 18-35 AND estado_civil == "soltero"
R3: viajes         ← viaja_frecuentemente == True
R4: mascotas       ← tiene_mascota == True
R5: hogar          ← es_propietario_vivienda == True
R6: movilidad      ← tiene_vehiculo is not None
R7: vida_deudor    ← tiene_deuda_activa == True
```

### R8–R13: Compound Segment Rules (affiliate category + life stage)
| Rule | Category | Segment | Products |
|------|----------|---------|----------|
| R8 | A | LAMBDA (sin grupo familiar) | vida, hogar |
| R9 | A | RHO (monoparental) | vida, accidentes |
| R10 | A | EPSILON (nuclear) | vida, hogar |
| R11 | B | any | accidentes, movilidad |
| R12 | C | any | All 6 (vida+hogar high, rest medium) |
| R13 | any | IOTA (pareja) | vida, hogar |

## Tools (FastMCP)
- `recommend_insurance(profile, documento?)` — Recommend products by profile + optional document lookup
  - Profile fields: tiene_mascota, tiene_vehiculo, es_propietario_vivienda, familia_con_hijos, preocupacion, edad, estado_civil, viaja_frecuentemente, tiene_deuda_activa, salario, categoria_afiliacion
- `quote_insurance(product_id, profile)` — Quote premium for a specific product
  - Product IDs: vida, accidentes, viajes, mascotas, hogar, movilidad, vida_deudor
  - Or catalog IDs: movilidad_carro, mascotas_perro_gato, personal_vida, hogar_contenido, etc.
- `create_policy(data)` — Create a policy
- `validate_coverage(tipo_documento, numero_documento)` — Validate existing coverage
- `create_claim(data)` — Start a claim
- `claim_status(claim_id)` — Check claim status

## State Machine
```
DISCOVERY → RISK → RECOMMENDATION → QUOTE → DATA_COLLECTION → PAYMENT → POLICY_CREATED
```

## Key Forms por Producto
- Seguro Accidentes Personales: datos personales, cobertura deseada, beneficiarios
- Seguro Exequial: datos personales, plan funerario, beneficiarios
- Póliza de Salud: datos personales, cobertura médica, red preferida
- Seguro de Vida: datos personales, beneficiarios, monto asegurado
- Vida y Ahorro: datos personales, beneficiarios, monto ahorro/protección
- Asistencia Viajes: datos personales, destino, duración, cobertura
